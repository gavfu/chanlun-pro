# 项目概览

## 项目定位

chanlun-pro 是一套**基于缠中说禅理论的量化分析与交易系统**。它将缠论中的分笔、分段、中枢、背驰、买卖点等概念程序化，提供了从行情数据获取、缠论指标计算、策略回测、到实盘交易的完整链路。

项目原作者：Wang Xu，GitHub: [yijixiuxin/chanlun-pro](https://github.com/yijixiuxin/chanlun-pro)

我们在 `chan` 分支上进行二次开发。核心改动是用自行实现的 `cl_open.py` 替代了 PyArmor 加密的缠论引擎，目标是逐步实现完整的缠论指标体系，并基于此进行加密货币的策略回测与实盘交易。

## 核心功能

1. **缠论计算引擎** — 逐 Bar 增量计算：K 线合并(包含处理) → 分型识别 → 笔构建 → 线段/走势段/趋势段 → 中枢 → 背驰 → 买卖点
2. **多市场数据接入** — 统一的 `Exchange` 抽象层，支持 10+ 数据源，本地 DB 缓存
3. **Web 可视化** — Flask + Tornado + TradingView 图表，展示缠论标注（分型/笔/线段/中枢/买卖点）
4. **策略回测** — 支持 signal（信号模式）和 trade（资金模式）两种回测，多进程并行，参数优化
5. **实盘交易** — 策略代码回测与实盘通用，仅切换数据源和交易执行层
6. **行情监控** — 定时扫描自选股，发现背驰/买卖点时推送飞书消息（支持图片）
7. **选股筛选** — 多种内置筛选策略（笔买卖点、线段买卖点、MA 过滤等）

## 技术栈

| 类别 | 技术/工具 |
|------|----------|
| 语言 | Python 3.11+ |
| 数据处理 | pandas 2.1、numpy 1.26.4、scipy |
| 技术指标 | TA-Lib (C 语言加速)、mytt |
| 交易所接口 | ccxt (Binance 等)、futu-api、ib-insync、tqsdk、alpaca-py、polygon-api-client |
| 数据库 | SQLite(默认) / MySQL(MariaDB)、Redis(可选) |
| ORM | SQLAlchemy |
| Web 框架 | Flask + Tornado (WSGI) |
| 图表 | pyecharts (Jupyter)、TradingView Charting Library (Web) |
| 任务调度 | APScheduler (TornadoScheduler) |
| 浏览器自动化 | Playwright (截图推送) |
| 消息推送 | 飞书(Lark) SDK、钉钉 Webhook |
| 代码加密 | PyArmor |
| 进程管理 | PM2 (生产环境) |
| 包管理 | pip / uv / conda |

## 一句话理解工作流

```
数据同步脚本(crontab) → DB 存储 → 策略回测/参数优化 (BackTest)
                                  → Web 可视化 (Flask+TradingView)
                                  → 实盘交易 (Trader) → 飞书消息推送
```
