# 架构设计与模块划分

## 分层架构

chanlun-pro 采用了清晰的分层架构，自底向上依次是：

```
┌─────────────────────────────────────────────────────────┐
│                     应用层 (Application)                  │
│  Web UI (Flask+TradingView)  │  Jupyter Notebook  │ CLI  │
├─────────────────────────────────────────────────────────┤
│                   业务逻辑层 (Business Logic)              │
│  策略 (Strategy)  │  回测 (BackTest)  │  监控 (Monitor)    │
│  选股 (XuanGu)    │  实盘交易 (Trader)                     │
├─────────────────────────────────────────────────────────┤
│                   核心计算层 (Core Engine)                  │
│  缠论引擎 (CL)  │  多级别分析 (MultiLevelAnalyse)          │
│  MACD/技术指标   │  图表渲染 (kcharts)                      │
├─────────────────────────────────────────────────────────┤
│                   数据接入层 (Data Access)                  │
│  Exchange 抽象层  │  DB (SQLAlchemy)  │  FileDB (Pickle)   │
│  Redis            │  消息推送 (飞书/钉钉)                   │
├─────────────────────────────────────────────────────────┤
│                   基础设施层 (Infrastructure)               │
│  config.py  │  fun.py  │  base.py  │  PyArmor Runtime     │
└─────────────────────────────────────────────────────────┘
```

## 核心设计原则

### 1. 统一接口，回测与实盘复用

这是整个系统最重要的设计决策。策略代码在回测和实盘中**完全相同**，只是底层的 `MarketDatas` 和 `Trader` 实现不同：

```
                    Strategy (策略逻辑不变)
                         │
              ┌──────────┴──────────┐
              ▼                     ▼
     回测 (BackTest)            实盘 (Live)
              │                     │
   BackTestKlines (回放)   OnlineMarketDatas (实时)
   BackTestTrader (模拟)   TraderCurrency (真实下单)
```

### 2. 增量计算

缠论引擎采用逐 Bar 增量计算方式。`process_klines()` 方法可以持续喂入新数据，已计算过的部分不会重新计算。这带来两个好处：
- **回测效率**：不需要每个时间点重算全部历史
- **实盘无缝**：每次收到新 K 线时只需增量更新

### 3. 工厂模式 + 单例

交易所访问采用工厂模式（`get_exchange(market)`）+ 单例模式（`@fun.singleton`），确保全局只有一个交易所实例，避免重复创建连接。

## 核心抽象接口

### ICL — 缠论计算接口

定义在 `cl_interface.py`，所有缠论计算引擎必须实现此接口：

```python
class ICL(metaclass=ABCMeta):
    # 输入
    def process_klines(self, klines: pd.DataFrame): ...
    
    # 基础属性
    def get_code(self) -> str: ...
    def get_frequency(self) -> str: ...
    def get_config(self) -> dict: ...
    
    # 原始数据
    def get_src_klines(self) -> List[Kline]: ...
    def get_klines(self) -> List: ...        # 根据配置返回原始或合并K线
    def get_cl_klines(self) -> List[CLKline]: ...
    def get_idx(self) -> dict: ...           # MACD 等指标
    
    # 缠论结构
    def get_fxs(self) -> List[FX]: ...       # 分型
    def get_bis(self) -> List[BI]: ...       # 笔
    def get_xds(self) -> List[XD]: ...       # 线段
    def get_zsds(self) -> List: ...          # 走势段
    def get_qsds(self) -> List: ...          # 趋势段
    
    # 中枢
    def get_bi_zss(self, zs_type) -> List[ZS]: ...
    def get_xd_zss(self, zs_type) -> List[ZS]: ...
    def get_zsd_zss(self) -> List[ZS]: ...
    def get_qsd_zss(self) -> List[ZS]: ...
    
    # 背驰判断
    def beichi_pz(self, zs, now_line) -> tuple: ...   # 盘整背驰
    def beichi_qs(self, lines, zss, now_line) -> tuple: ...  # 趋势背驰
    def zss_is_qs(self, one_zs, two_zs) -> str: ...   # 是否构成趋势
```

## 数据流向

### 回测流程

```
BackTest.run()
  │
  ├─ for each date in date_range:
  │    │
  │    ├─ BackTestKlines.next()          ← 推进时间
  │    │
  │    ├─ for each code:
  │    │    │
  │    │    ├─ BackTestTrader.run(code)
  │    │    │    │
  │    │    │    ├─ Strategy.close()      ← 先检查是否平仓
  │    │    │    │    └─ MarketDatas.get_cl_data()
  │    │    │    │         └─ CL.process_klines()  ← 增量计算缠论
  │    │    │    │
  │    │    │    └─ Strategy.open()       ← 再检查是否开仓
  │    │    │         └─ (同上)
  │    │    │
  │    │    └─ BackTestTrader.execute()   ← 执行交易信号
  │    │
  │    └─ BackTestTrader.update_position_record()  ← 更新持仓盈亏
  │
  └─ BackTest.result()                   ← 汇总回测结果
```

### 实盘流程

```
script/trader/reboot_trader_currency.py
  │
  ├─ 初始化 ExchangeBinance、TraderCurrency、OnlineMarketDatas
  │
  └─ while True (每5分钟):
       │
       ├─ OnlineMarketDatas.clear_cache()    ← 清除缓存
       │
       ├─ 获取 top 30 交易量代币 + 当前持仓代币
       │
       ├─ for each code:
       │    │
       │    └─ TraderCurrency.run(code)
       │         │
       │         ├─ Strategy.close()          ← 检查平仓
       │         │    └─ OnlineMarketDatas.get_cl_data()
       │         │         └─ ExchangeBinance.klines()  ← 实时行情
       │         │              └─ CL.process_klines()
       │         │
       │         ├─ Strategy.open()           ← 检查开仓
       │         │
       │         └─ TraderCurrency.execute()  ← 真实下单
       │              ├─ ExchangeBinance.order()  ← Binance API
       │              └─ utils.send_fs_msg()      ← 飞书通知
       │
       └─ TraderCurrency.save_to_pkl()       ← 持久化状态到 Redis
```

## 关键设计模式

| 模式 | 应用位置 | 目的 |
|------|---------|------|
| **抽象工厂** | `exchange/__init__.py` → `get_exchange()` | 根据配置动态创建交易所实例 |
| **单例** | `@fun.singleton` 装饰器，用于 Exchange 实例 | 避免重复创建 API 连接 |
| **策略模式** | `Strategy` ABC + 具体策略类 | 策略可插拔，回测/实盘通用 |
| **模板方法** | `BackTestTrader.run()` | 固定的 close → open → execute 流程 |
| **适配器** | 各 `exchange_*.py` | 将不同数据源 API 适配为统一 Exchange 接口 |
| **观察者** | APScheduler 监听器 | 定时任务状态监控 |
| **缓存** | `file_db.py` (Pickle 缓存)、`BackTestKlines` 内存缓存 | 减少重复计算 |
