# 缠论计算引擎

## 概述

缠论计算引擎是整个项目的核心。它将 K 线数据作为输入，逐步计算出缠论中的各级别结构：

```
原始 K 线 → 合并 K 线(包含处理) → 分型 → 笔 → 线段 → 走势段/趋势段
                                              → 笔中枢 → 线段中枢 → ...
                                              → 背驰检测 → 买卖点判定
```

> **当前状态**：`cl_open.py` 是我们在 `chan` 分支上自行实现的开源版本（commit `157e2e7`，2026-02-09），用于替代 PyArmor 加密的 `cl_pyarmor.py`。第一阶段已实现"笔 + 笔中枢"，后续将继续补全线段、中枢、买卖点等完整缠论指标。详见 [PyArmor 加密模块分析](./08-PyArmor加密模块分析.md)。

## 入口文件

`cl.py` 只有一行有效代码：

```python
from chanlun.cl_open import CL
```

所有使用方通过 `from chanlun.cl import CL` 导入。这个设计使得引擎切换和上游 merge 都只需改动一行。

## 数据结构（cl_interface.py）

### K 线类

#### Kline — 原始 K 线

```python
class Kline:
    index: int           # 序号
    date: datetime       # 时间
    h: float             # 最高价
    l: float             # 最低价
    o: float             # 开盘价
    c: float             # 收盘价
    a: float             # 成交量
```

#### CLKline — 合并后的缠论 K 线

```python
class CLKline:
    k_index: int              # 极值原始 K 线在合并组中的索引
    date: datetime
    h, l, o, c, a: float
    klines: List[Kline]       # 被合并的原始 K 线列表
    index: int                # 合并 K 线序号
    n: int                    # 包含的原始 K 线数量
    q: bool                   # 是否有跳空缺口
    up_qs: Optional[str]      # 合并前的趋势方向
```

### 分型 (FX)

分型是 3 根连续合并 K 线形成的特征结构：

```python
class FX:
    type: str                 # "ding" (顶分型) 或 "di" (底分型)
    k: CLKline                # 中间那根 K 线
    klines: List[CLKline]     # 3 根 K 线
    val: float                # 分型值（顶取最高，底取最低）
    index: int
    done: bool                # 是否已确认
    
    def ld(self) -> int:      # 分型力度 (0-5)
    def high(self, qj_type, qy_type) -> float:  # 分型高点
    def low(self, qj_type, qy_type) -> float:   # 分型低点
```

### 笔 (BI) — 继承自 LINE

笔是连接相邻顶分型和底分型的线段结构：

```python
class LINE:
    start: FX                 # 起始分型
    end: FX                   # 结束分型
    high: float               # 最高点
    low: float                # 最低点
    zs_high: float            # 中枢上沿统计值（特征序列相关）
    zs_low: float             # 中枢下沿统计值
    type: str                 # "up" (向上) 或 "down" (向下)
    index: int

class BI(LINE):
    mmds: List[MMD]           # 买卖点列表
    bcs: List[BC]             # 背驰列表
    default_zs_type: str      # 默认中枢类型
    zs_type_mmds: Dict        # 按中枢类型分组的买卖点
    zs_type_bcs: Dict         # 按中枢类型分组的背驰
    is_split: str             # 笔拆分标记
    
    def is_done(self) -> bool       # 笔是否完成
    def mmd_exists(self, checks, zs_type) -> bool  # 是否存在指定买卖点
    def bc_exists(self, bc_types, zs_type) -> bool  # 是否存在指定背驰
    def line_mmds(self, zs_type) -> list   # 获取买卖点（支持 | 和 & 运算符）
    def get_ld(self, cl) -> dict    # 获取 MACD 力度（DIF/DEA/HIST）
```

### 线段 (XD) — 也继承自 LINE

线段由多笔组成，通过特征序列的分型来确定端点：

```python
class XD(LINE):
    start_line: LINE          # 起始笔
    end_line: LINE            # 结束笔
    ding_fx: XLFX             # 顶特征序列分型
    di_fx: XLFX               # 底特征序列分型
    tzxls: List[TZXL]         # 特征序列列表
    done: bool                # 线段是否完成
    mmds: List[MMD]
    bcs: List[BC]
```

### 特征序列 (TZXL) 与序列分型 (XLFX)

用于线段端点的确定：

```python
class TZXL:                   # 特征序列元素
    bh_direction: str         # 包含方向
    line: LINE                # 对应的笔
    pre_line: LINE            # 前一笔
    lines: List[LINE]         # 包含的笔列表
    done: bool
    max: float
    min: float

class XLFX:                   # 序列分型
    type: str                 # "ding" 或 "di"
    xl: TZXL                  # 关键序列元素
    xls: List[TZXL]           # 3 个序列元素
    qk: bool                  # 是否有缺口
    done: bool
```

### 中枢 (ZS)

```python
class ZS:
    zs_type: str              # "bi"(笔中枢)、"xd"(线段中枢)、"zsd"(走势段中枢)
    start: FX                 # 中枢起点
    end: FX                   # 中枢终点
    lines: List[LINE]         # 构成中枢的线
    zg: float                 # 中枢高点（重叠区间上沿）
    zd: float                 # 中枢低点（重叠区间下沿）
    gg: float                 # 中枢区间最高点
    dd: float                 # 中枢区间最低点
    type: str                 # "up"(上升)、"down"(下降)、"zd"(震荡)
    level: int                # 中枢级别
    done: bool                # 是否已完成
    real: bool                # 是否为真实中枢
    
    def zf(self) -> float:    # 中枢振幅百分比 = (zg - zd) / zd * 100
    def r2(self, klines) -> float:  # 线性回归 R² 值
    def zs_mmds(self, zs_type) -> List[str]:  # 中枢相关买卖点
```

### 买卖点 (MMD) 和背驰 (BC)

```python
class MMD:
    name: str                 # 买卖点名称 (见下表)
    zs: ZS                    # 关联的中枢
    msg: str                  # 说明信息

class BC:
    type: str                 # 背驰类型: "bi"/"xd"/"zsd"/"pz"/"qs"
    zs: Optional[ZS]         # 关联的中枢
    compare_line: LINE        # 比较对象（上一个同向线段）
    compare_lines: List[LINE]
    bc: bool                  # 是否确认背驰
```

#### 买卖点类型一览

| 名称 | 含义 | 缠论原文对应 |
|------|------|-------------|
| `1buy` | 第一类买点 | 趋势下跌末端的反转买点 |
| `2buy` | 第二类买点 | 第一类买点后的回踩不创新低 |
| `3buy` | 第三类买点 | 离开中枢后的回拉不回中枢 |
| `l2buy` | 类二买点 | 类似二买的结构（自定义扩展） |
| `l3buy` | 类三买点 | 类似三买的结构（自定义扩展） |
| `1sell` | 第一类卖点 | 趋势上涨末端的反转卖点 |
| `2sell` | 第二类卖点 | 第一类卖点后的反弹不创新高 |
| `3sell` | 第三类卖点 | 离开中枢后的回拉不回中枢 |
| `l2sell` | 类二卖点 | 类似二卖的结构 |
| `l3sell` | 类三卖点 | 类似三卖的结构 |
| `down_bi_bc_buy` | 下跌笔背驰买 | 下跌笔出现 MACD 背驰 |
| `up_bi_bc_sell` | 上涨笔背驰卖 | 上涨笔出现 MACD 背驰 |

## 计算流程（cl_open.py）

### 主入口：`process_klines(klines: pd.DataFrame)`

接收 DataFrame（需包含 `date`, `high`, `low`, `open`, `close`, `volume` 列），支持增量调用。

内部调用链：

```
process_klines()
  ├─ _build_src_klines()    # DataFrame → List[Kline]
  ├─ _merge_klines()        # K 线合并（包含处理）
  ├─ _find_fxs()            # 分型识别
  ├─ _filter_fxs()          # 分型过滤（交替、包含检查）
  ├─ _build_bis()           # 笔构建
  ├─ _update_bi_highlow()   # 笔高低点更新 + 标准化
  ├─ _build_bi_zss()        # 笔中枢构建
  └─ _compute_macd()        # MACD 计算
```

### 步骤 1：K 线合并（包含处理）

```
_merge_klines(src_klines) → List[CLKline]
```

将原始 K 线做包含处理：当两根相邻 K 线存在包含关系（一根完全包含另一根）时，合并为一根。合并方向取决于当前趋势方向：
- **上升趋势**：取两者的高中取高、低中取高
- **下降趋势**：取两者的高中取低、低中取低

同时检测跳空缺口（`q` 标记）。

### 步骤 2：分型识别

```
_find_fxs(cl_klines) → List[FX]
```

遍历合并 K 线序列，识别顶分型和底分型：
- **顶分型**：中间 K 线的最高价 > 两侧 K 线的最高价
- **底分型**：中间 K 线的最低价 < 两侧 K 线的最低价

然后通过 `_filter_fxs()` 确保：
- 顶底交替出现
- 处理分型包含关系（根据 `fx_bh` 配置）

### 步骤 3：笔构建

```
_build_bis(fxs) → List[BI]
```

连接相邻顶底分型构成笔，支持 4 种笔类型：

| 配置值 | 类型 | 规则 |
|--------|------|------|
| `bi_type_old` | 传统笔 | 顶底间至少 5 根 K 线 |
| `bi_type_new` | 新笔 | 顶底间至少 4 根独立 K 线 |
| `bi_type_jdb` | 见底笔 | 放宽条件的简化笔 |
| `bi_type_dd` | 顶底笔 | 只要求顶高于底 |

额外特性：
- **笔拆分**：当一笔内某 K 线与前后 K 线形成反方向的交叉超过阈值时（`bi_split_k_cross` 配置），自动拆分
- **次高低分型**（`bi_fx_cgd`）：允许非最高/最低分型作为笔端点

### 步骤 4：笔高低点更新

```
_update_bi_highlow() → 更新 BI.high / BI.low
```

根据 `bi_qj` 配置确定笔的高低点取值方式：

| 配置值 | 取值方式 |
|--------|---------|
| `bi_qj_dd` | 取起止分型值的极值 |
| `bi_qj_ck` | 取合并 K 线的极值 |
| `bi_qj_k` | 取原始 K 线的极值 |

如果开启 `bi_bzh`（笔标准化），则额外计算 `zs_high` 和 `zs_low`。

### 步骤 5：中枢构建

```
create_dn_zs(zs_type, lines) → List[ZS]
```

从笔列表构建中枢，规则：
1. 取连续 3 笔（或更多，取决于 `zs_cd` 配置），计算其重叠区间
2. 若重叠区间存在（`zg > zd`），则构成中枢
3. 后续笔如果仍在中枢区间内，则扩展中枢
4. 根据 `zs_wzgx` 配置判断两个中枢之间是否形成趋势

### 步骤 6：MACD 计算

```
_compute_macd() → 填充 self.idx
```

使用 `talib.MACD()` 计算 MACD 指标（DIF/DEA/HIST），参数可通过 `idx_macd_fast/slow/signal` 配置。

## 多级别分析（cl_analyse.py）

### MultiLevelAnalyse — 跨周期分析

将高级别的笔/线段映射到低级别，分析低级别内部结构：

```python
class MultiLevelAnalyse:
    def low_level_qs(self, up_cd, up_line, low_cd) -> LOW_LEVEL_QS:
        """分析高级别线段在低级别中的走势结构（中枢数量、趋势/盘整、背驰情况）"""
    
    def up_bi_low_level_qs(self, up_cd, low_cd) -> LOW_LEVEL_QS:
        """分析高级别最后一笔在低级别的走势"""
    
    def up_xd_low_level_qs(self, up_cd, low_cd) -> LOW_LEVEL_QS:
        """分析高级别最后一线段在低级别的走势"""
```

`LOW_LEVEL_QS` 返回结构包括：
- `zs_num`：低级别中枢数量
- `line_num`：低级别线段数量
- `qs`：是否构成趋势
- `pz`：是否构成盘整
- `qs_bc` / `pz_bc` / `line_bc`：各类型背驰判断

## 买卖点判定规则

| 信号 | 条件 |
|------|------|
| **1买** | 两个同级别中枢形成下降趋势 + 趋势背驰；或 3卖 + 背驰（含下跌中枢） |
| **1卖** | 两个同级别中枢形成上升趋势 + 趋势背驰；或 3买 + 背驰（含上涨中枢） |
| **2买** | 1买之后的回踩不创新低 |
| **2卖** | 1卖之后的反弹不创新高 |
| **3买** | 向上离开中枢后的回踩不进入中枢 |
| **3卖** | 向下离开中枢后的反弹不进入中枢 |
| **类2买/卖** | 前同向线段有2买/卖，当前重叠形成中枢，低点高于/高点低于2买/卖的极值 |
| **类3买/卖** | 前同向线段有3买/卖，当前力度更弱 |

### 背驰类型

| 类型 | 判定方式 |
|------|---------|
| **笔/段/走势段背驰** | 3 段结构中，第 3 段创新极值但 MACD 力度弱于第 1 段 |
| **盘整背驰** | 中枢内部，出入段的 MACD 力度比较 |
| **趋势背驰** | 2 个以上同向中枢，最后一段创新极值但力度衰减 |
