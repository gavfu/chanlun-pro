# 行情数据与交易所接入

## Exchange 抽象层

所有市场数据和交易操作都通过统一的 `Exchange` 抽象基类（定义在 `exchange/exchange.py`）进行。

### 核心接口

```python
class Exchange(ABC):
    # 元信息
    def default_code(self) -> str: ...          # 默认展示代码
    def support_frequencys(self) -> dict: ...   # 支持的K线周期 {"d": "日线", "30m": "30分钟", ...}
    def all_stocks(self) -> dict: ...           # 所有可交易标的
    def now_trading(self) -> bool: ...          # 当前是否交易时间
    
    # 行情数据
    def klines(self, code, frequency, args={}) -> pd.DataFrame: ...  # K线数据
    def ticks(self, codes) -> dict: ...         # 实时 tick
    def stock_info(self, code) -> dict: ...     # 标的信息
    
    # 交易接口
    def balance(self) -> dict: ...              # 账户余额
    def positions(self, code='') -> dict: ...   # 持仓信息
    def order(self, code, o_type, amount, args={}) -> dict: ...  # 下单
```

### 工厂函数

`exchange/__init__.py` 中的 `get_exchange(market)` 是交易所实例的统一入口：

```python
from chanlun.exchange import get_exchange
from chanlun.base import Market

ex = get_exchange(Market.CURRENCY)  # 获取 Binance 合约实例
```

它根据 `config.py` 中的配置决定使用哪个具体实现，并以单例方式缓存：

| 市场 | 配置键 | 可选值 |
|------|--------|--------|
| A 股 | `EXCHANGE_A` | `tdx`, `futu`, `baostock`, `db`, `qmt` |
| 港股 | `EXCHANGE_HK` | `tdx_hk`, `futu`, `db` |
| 期货 | `EXCHANGE_FUTURES` | `tq`, `tdx_futures`, `db` |
| 数字货币(合约) | `EXCHANGE_CURRENCY` | `binance`, `db` |
| 数字货币(现货) | `EXCHANGE_CURRENCY_SPOT` | `binance_spot`, `db` |
| 美股 | `EXCHANGE_US` | `alpaca`, `polygon`, `ib`, `tdx_us`, `db` |

## Binance 合约（exchange_binance.py）

### 特点

- 基于 `ccxt.binanceusdm`（USDT 永续合约）
- 单例模式（`@fun.singleton`）
- **DB 优先策略**：`klines()` 先查本地 DB，只增量补充在线数据
- 支持 15 种 K 线周期，部分通过频率转换合成（如 10m 从 5m 合成）
- 24/7 交易（`now_trading()` 永远返回 `True`）
- 自动重试（`tenacity`，最多 3 次，随机 1-5 秒间隔）

### K 线获取流程

```
klines(code, frequency)
  │
  ├─ ExchangeDB.klines()                  ← 查本地缓存
  │
  ├─ 如果在线数据可用且不仅使用DB:
  │    └─ increment_klines_by_online()     ← 增量从 Binance API 获取
  │         └─ ccxt.fetch_ohlcv()          ← 每次最多 1000 条
  │              └─ 循环翻页，最多 10000 条
  │
  ├─ 合并 DB + 在线数据
  │
  ├─ 去重（按 date 排序去重）
  │
  └─ 返回最多 10000 条 K 线
```

### 支持的 K 线周期

| 周期 | 来源 |
|------|------|
| `w`, `d`, `12h`, `8h`, `6h`, `4h`, `60m`, `30m`, `15m`, `5m`, `1m` | Binance 原生 |
| `3h` | 从 `60m` 合成 |
| `10m` | 从 `5m` 合成 |
| `3m` | 从 `1m` 合成 |
| `2m` | 从 `1m` 合成 |

### 交易接口

```python
# 下单类型
order(code, 'open_long', amount)    # 开多（市价）
order(code, 'open_short', amount)   # 开空（市价）
order(code, 'close_long', amount)   # 平多（市价）
order(code, 'close_short', amount)  # 平空（市价）
```

下单前会自动设置杠杆倍数。

## Binance 现货（exchange_binance_spot.py）

与合约版基本相同，主要区别：
- 使用 `ccxt.binance`（现货）
- 不需要 `:USDT` 后缀
- **交易接口未实现**（`balance()`, `positions()`, `order()` 会抛出 `RuntimeWarning`）
- 更少的 K 线周期（无 8h, 6h, 3h, 3m, 2m）

> 如果你需要做现货交易，需要自行实现 `balance()`、`positions()`、`order()` 方法。

## DB 行情（exchange_db.py）

`ExchangeDB` 是一个基于本地数据库的行情源，主要用于：
- 回测时提供历史数据
- 作为在线数据的本地缓存
- 离线分析

```python
class ExchangeDB(Exchange):
    def __init__(self, market: str):
        """market: 'a', 'hk', 'us', 'currency', 'currency_spot', 'futures'"""
    
    def klines(self, code, frequency, args={}):
        """从本地 DB 查询 K 线数据，支持 start_date 参数"""
    
    def insert_klines(self, code, frequency, klines_df):
        """批量插入 K 线数据到 DB"""
    
    def query_last_datetime(self, code, frequency):
        """查询最后一条数据的时间"""
```

## 数据库层（db.py）

### 存储架构

使用 SQLAlchemy ORM，支持 SQLite（默认）和 MySQL。

**K 线存储**：每个市场+代码+周期 对应一张独立的数据库表，表名格式：`klines_{market}_{code}_{frequency}`

例如 `klines_currency_BTC_USDT_30m`。

### ORM 模型

| 模型 | 用途 |
|------|------|
| `TableByCache` | 通用键值缓存（支持过期时间） |
| `TableByZxGroup` | 自选股分组 |
| `TableByZixuan` | 自选股列表 |
| `TableByAlertTask` | 监控告警任务 |
| `TableByAlertRecord` | 告警历史记录 |
| `TableByTVMarks` | TradingView 图表标注 |
| `TableByOrder` | 订单记录 |
| `TableByTVCharts` | 图表布局保存 |
| `TableByAIAnalyse` | AI 分析结果 |

## K 线频率转换

不同市场的 K 线频率转换逻辑不同，定义在 `exchange/exchange.py`：

### 股票频率转换

`convert_stock_kline_frequency(klines, to_f)` — A股/港股：
- 日内周期使用 pandas resample
- 60m/120m 使用显式时间段分组（考虑 A 股午间休市）
- 日/周/月以 15:00 收盘对齐

### 加密货币频率转换

`convert_currency_kline_frequency(klines, to_f)` — 加密货币：
- 日线使用 08:00 AM 作为日界（Binance UTC+8 约定）
- 其他周期使用标准 resample

### 期货频率转换

`convert_futures_kline_frequency(klines, to_f)` — 期货：
- 考虑交易时段（日盘 9:00-15:00、夜盘 21:00-23:00）
- 60m/120m 使用特定的时间段分组

## 文件缓存层（file_db.py）

`FileCacheDB` 提供 Pickle 格式的文件缓存，主要用于：
- Web 端 CL 计算结果缓存（避免每次请求重算）
- TDX 行情数据缓存（减少网络请求）

```python
fdb = FileCacheDB()  # 全局单例

# 获取/缓存 CL 数据
cl_data = fdb.get_web_cl_data(market, code, frequency, klines, cl_config)

# 缓存 TDX K线
fdb.save_tdx_klines(market, code, frequency, klines_df)
klines = fdb.get_tdx_klines(market, code, frequency)
```

缓存失效条件：
- 超过文件年龄限制
- CL 配置变更（约 40 个关键配置键任一变化）
- 手动清除（`clear_web_cl_data()`）
- 全局更新日期（`cl_update_date`）

## 数据同步流程

以加密货币为例（`script/crontab/reboot_sync_currency_klines.py`）：

```python
# 1. 创建在线交易所和 DB 交易所
ex_online = ExchangeBinance()
ex_db = ExchangeDB("currency")

# 2. 获取所有交易对
all_stocks = ex_online.all_stocks()

# 3. 对每个交易对的每个周期增量同步
for code in all_stocks:
    for freq in ["w", "d", "4h", "60m", "30m", "15m", "10m", "5m", "1m"]:
        # 查询 DB 中最后一条数据的时间
        last_dt = ex_db.query_last_datetime(code, freq)
        
        # 从 Binance API 获取增量数据
        new_klines = ex_online.klines(code, freq, args={"start_date": last_dt})
        
        # 写入 DB
        ex_db.insert_klines(code, freq, new_klines)
```

### 同步脚本一览

| 脚本 | 数据源 | 目标 |
|------|--------|------|
| `reboot_sync_currency_klines.py` | Binance 合约 | 全部 USDT 交易对 |
| `reboot_sync_currency_spot_klines.py` | Binance 现货 | 指定交易对（默认 BTC/USDT） |
| `reboot_sync_a_klines.py` | Baostock | A 股 |
| `reboot_sync_hk_klines.py` | 富途 API | 港股 |
| `reboot_sync_futures_klines.py` | 天勤 | 国内期货 |
| `reboot_sync_us_klines.py` | 多源 | 美股 |
