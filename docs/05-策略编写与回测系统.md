# 策略编写与回测系统

## 策略框架概述

chanlun-pro 的策略框架基于三个核心抽象：

- **`Strategy`** — 纯信号逻辑：判断开仓/平仓，不管资金和仓位
- **`MarketDatas`** — 数据提供：返回 K 线和缠论计算结果
- **`Trader`** — 交易执行：管理仓位、计算盈亏、执行订单

```
Strategy.open()  → List[Operation]  → Trader.execute()  → 开仓
Strategy.close() → Operation|None   → Trader.execute()  → 平仓
```

## Strategy 基类

定义在 `backtesting/base.py`：

```python
class Strategy(ABC):
    @abstractmethod
    def open(self, code: str, market_data: MarketDatas, 
             poss: Dict[str, POSITION]) -> List[Operation]:
        """
        判断是否开仓。
        
        参数:
            code: 标的代码，如 "ETH/USDT"
            market_data: 行情数据提供者
            poss: 当前持仓字典 {mmd_name: POSITION}
        返回:
            Operation 列表。空列表 = 不开仓
        """
        pass
    
    @abstractmethod
    def close(self, code: str, mmd: str, pos: POSITION, 
              market_data: MarketDatas) -> Union[Operation, None, List[Operation]]:
        """
        判断是否平仓。
        
        参数:
            code: 标的代码
            mmd: 持仓的买卖点名称
            pos: 当前持仓对象
            market_data: 行情数据提供者
        返回:
            Operation = 平仓，None = 持有
        """
        pass
```

## Operation 对象

```python
class Operation:
    code: str        # 标的代码
    opt: str         # "buy" (开仓) 或 "sell" (平仓)
    mmd: str         # 信号名称（如 "1buy", "3sell"）
    loss_price: float  # 止损价
    msg: str         # 日志信息
    info: dict       # 附加信息（可自定义）
    pos_rate: float  # 仓位比例 (0-1)，默认 1.0
    key: str         # 唯一标识（支持分批开平仓）
```

### 开仓 vs 平仓的约定

| opt | mmd 含义 | 方向 |
|-----|---------|------|
| `buy` | `*buy` (如 `1buy`, `3buy`) | 做多开仓 |
| `buy` | `*sell` (如 `1sell`, `3sell`) | 做空开仓 |
| `sell` | `*buy` | 做多平仓 |
| `sell` | `*sell` | 做空平仓 |

简单说：`buy` = 开仓，`sell` = 平仓。mmd 中带 `buy` 的是多头信号，带 `sell` 的是空头信号。

## POSITION 对象

```python
class POSITION:
    code: str             # 标的代码
    mmd: str              # 开仓信号名
    type: str             # "做多" 或 "做空"
    balance: float        # 开仓金额
    price: float          # 开仓价格
    amount: float         # 持仓数量
    loss_price: float     # 止损价格
    open_date: str        # 开仓日期
    open_datetime: datetime  # 开仓精确时间
    close_datetime: datetime # 平仓时间
    profit_rate: float    # 当前盈亏率 (%)
    max_profit_rate: float   # 历史最大盈利率
    max_loss_rate: float     # 历史最大亏损率
    open_msg: str         # 开仓说明
    close_msg: str        # 平仓说明
    info: dict            # 自定义附加信息
```

## 编写策略示例

### 最简单的策略：笔级别买卖点

```python
from chanlun.backtesting.base import *

class MySimpleStrategy(Strategy):
    
    def open(self, code, market_data, poss):
        opts = []
        # 获取主周期缠论数据
        cd = market_data.get_cl_data(code, market_data.frequencys[0])
        
        bis = cd.get_bis()
        if len(bis) < 2:
            return opts
        
        # 最后一根已完成的笔
        last_bi = bis[-1] if bis[-1].is_done() else bis[-2]
        
        # 检查买卖点
        for mmd in last_bi.line_mmds():
            mmd_name = mmd.name
            if mmd_name in poss:  # 已有同信号持仓
                continue
            
            # 检查笔停顿（确认信号）
            if not self.bi_td(last_bi, cd):
                continue
            
            opts.append(Operation(
                code=code,
                opt="buy",
                mmd=mmd_name,
                loss_price=last_bi.low if 'buy' in mmd_name else last_bi.high,
                msg=f"笔级别 {mmd_name} 信号"
            ))
        
        return opts
    
    def close(self, code, mmd, pos, market_data):
        cd = market_data.get_cl_data(code, market_data.frequencys[0])
        
        # 止损检查
        price = market_data.last_k_info(code)
        loss_opt = self.check_loss(mmd, pos, price)
        if loss_opt:
            return loss_opt
        
        bis = cd.get_bis()
        last_bi = bis[-1] if bis[-1].is_done() else bis[-2]
        
        # 多头：找到反向笔有卖点时平仓
        if "buy" in mmd and last_bi.type == "up":
            for sell_mmd in last_bi.line_mmds():
                if "sell" in sell_mmd.name:
                    return Operation(code=code, opt="sell", mmd=mmd)
        
        # 空头：找到反向笔有买点时平仓
        if "sell" in mmd and last_bi.type == "down":
            for buy_mmd in last_bi.line_mmds():
                if "buy" in buy_mmd.name:
                    return Operation(code=code, opt="sell", mmd=mmd)
        
        return None
```

## 回测系统

### BackTest 引擎

定义在 `backtesting/backtest.py`，是回测的顶层编排器。

#### 配置

```python
bt_config = {
    "save_file": "./my_backtest.pkl",         # 结果保存路径
    "strategy": MySimpleStrategy(),           # 策略实例
    "mode": "trade",                          # "signal" 或 "trade"
    "market": "currency",                     # 市场标识
    "base_code": "BTC/USDT",                  # 基准代码（确定时间轴）
    "codes": ["BTC/USDT", "ETH/USDT"],       # 回测标的列表
    "frequencys": ["30m", "5m"],              # 周期列表（大→小排列）
    "start_datetime": "2024-01-01 00:00:00",  # 开始时间
    "end_datetime": "2024-12-31 23:59:59",    # 结束时间
    "init_balance": 100000,                   # 初始资金
    "fee_rate": 0.0006,                       # 手续费率（含滑点）
    "max_pos": 2,                             # 最大同时持仓数
    "cl_config": {},                          # 缠论引擎配置（可选）
}

BT = BackTest(bt_config)
```

#### 运行

```python
# 单进程运行
BT.run(next_frequency="30m")

# 多进程运行（每个 code 一个进程）
BT.run_process(max_workers=4, next_frequency="30m")

# 保存结果
BT.save()
```

#### 结果分析

```python
# 打印配置
BT.info()

# 打印回测结果
BT.result()
# 输出: 总收益、年化收益、最大回撤、夏普比率、各买卖点胜率分布...

# pyfolio 分析
BT.result_by_pyfolio()

# 查看持仓记录
positions_df = BT.positions()

# 查看图表（带买卖标记）
BT.show_charts("ETH/USDT", "30m")
```

### 两种回测模式

#### signal 模式

- 不考虑资金限制，每个信号都开仓
- 固定 10 万元/仓
- 适合信号质量评估
- 支持多进程并行（每个 code 独立）

#### trade 模式

- 模拟真实资金管理
- 初始资金 → 按 max_pos 分配仓位
- 考虑手续费、滑点
- 不能多进程（因为资金共享）

### 回测数据引擎（BackTestKlines）

`backtest_klines.py` 中的 `BackTestKlines` 负责按时间顺序回放 K 线：

```python
class BackTestKlines(MarketDatas):
    def __init__(self, market, start_date, end_date, frequencys, cl_config):
        self.load_kline_nums = 10000      # 每批加载K线数
        self.cl_data_kline_max_nums = 50000  # CL数据最大K线数（超出后重置）
    
    def init(self, base_code, frequency):
        """初始化时间轴"""
    
    def next(self, frequency):
        """推进到下一个时间点"""
    
    def get_cl_data(self, code, frequency, cl_config=None):
        """获取截至当前时间点的缠论数据（增量更新）"""
```

关键特性：
- **增量计算**：CL 引擎只处理新增 K 线
- **内存管理**：当 K 线数超过 `cl_data_kline_max_nums` 时自动重置
- **惰性加载**：CL 数据只在被策略访问时才计算

### 信号→交易转换（SignalToTrade）

## 回测评估指标

`BackTest.result()` 输出的指标包括：

| 指标 | 说明 |
|------|------|
| 总收益率 | 最终净值 / 初始资金 - 1 |
| 年化收益率 | 按回测时间折算的年化 |
| 最大回撤 | 净值曲线的最大回撤百分比 |
| 夏普比率 | 风险调整后收益 |
| 收益回撤比 | 总收益 / 最大回撤 |
| 胜率 | 盈利次数 / 总交易次数 |
| 各买卖点胜率 | 按 1buy/2buy/3buy/... 分类统计 |
| 盈亏比 | 平均盈利 / 平均亏损 |

## 多周期策略要点

`frequencys` 参数必须从大周期到小周期排列，如 `["30m", "5m"]`。

在策略中获取不同周期数据：

```python
def open(self, code, market_data, poss):
    # 大周期（决策用）
    cd_large = market_data.get_cl_data(code, market_data.frequencys[0])  # 30m
    
    # 小周期（精细入场）
    cd_small = market_data.get_cl_data(code, market_data.frequencys[1])  # 5m
    
    # 注意：get_cl_data 是惰性计算的，未调用则不会消耗算力
```

> **关键注意**：`frequencys[0]` 是最大周期（用于确定迭代步长），`frequencys[-1]` 是最小周期（数据最细）。回测循环按最小周期逐 Bar 推进。
