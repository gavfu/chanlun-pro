# 部署与运维

## 环境搭建

### 前置依赖

| 依赖 | 用途 | 是否必需 |
|------|------|---------|
| Python 3.11+ | 运行环境 | ✅ 必需 |
| TA-Lib (C 库) | 技术指标计算加速 | ✅ 必需 |
| Git | 代码管理与更新 | 推荐 |
| Redis | 实盘状态持久化、跨进程共享 | 可选（实盘需要） |
| MySQL/MariaDB | 大量数据存储 | 可选（SQLite 可替代） |
| PM2 (Node.js) | 生产环境进程管理 | 可选 |
| 代理 (VPN) | 访问 Binance API | 加密货币必需 |

### macOS 安装步骤

```bash
# 1. 安装 TA-Lib C 库
brew install ta-lib

# 2. 创建 Python 环境（推荐 conda 或 uv）
# 方式 A: conda
conda create -n chanlun python=3.11
conda activate chanlun

# 方式 B: uv
curl -LsSf https://astral.sh/uv/install.sh | sh
uv venv --python 3.11
source .venv/bin/activate

# 3. 安装依赖
pip install -r requirements.txt
# 或使用 uv
uv sync

# 4. 将 src 加入 Python 路径
export PYTHONPATH="${PYTHONPATH}:$(pwd)/src"

# 5. 创建配置文件
cp src/chanlun/config.py.demo src/chanlun/config.py
# 编辑 config.py，填入你的 API Key 等配置

# 6. 验证环境
python check_env.py
```

## 配置文件（config.py）

从 `config.py.demo` 复制后修改。关键配置项：

### 基础配置

```python
# Web 服务
WEB_HOST = "127.0.0.1"     # 仅本地访问；用 "0.0.0.0" 允许外网
LOGIN_PWD = "your_password" # Web 登录密码，空串 = 无需登录

# 数据路径
DATA_PATH = ".chanlun_pro"  # 以 "." 开头则放在 ~/  下

# 代理（加密货币必需）
PROXY_HOST = "127.0.0.1"
PROXY_PORT = "7890"
```

### 数据库配置

```python
# SQLite（默认，无需额外安装）
DB_TYPE = "sqlite"

# MySQL（大量数据推荐）
DB_TYPE = "mysql"
DB_HOST = "127.0.0.1"
DB_PORT = 3306
DB_USER = "root"
DB_PWD = ""
DB_DATABASE = "chanlun_klines"
```

使用 MySQL 时需先创建数据库：

```sql
CREATE DATABASE chanlun_klines DEFAULT CHARACTER SET utf8mb4;
```

### 交易所配置

```python
# 加密货币
EXCHANGE_CURRENCY = "binance"        # 或 "db"（纯离线）
EXCHANGE_CURRENCY_SPOT = "binance_spot"
BINANCE_APIKEY = "your_api_key"
BINANCE_SECRET = "your_secret"

# A 股
EXCHANGE_A = "tdx"                   # 通达信（免费，延迟数据）
# EXCHANGE_A = "baostock"            # Baostock（免费，日线级别历史）

# 其他市场...
```

### 消息推送配置（飞书）

```python
FEISHU_KEYS = {
    "currency": {
        "app_id": "cli_xxx",
        "app_secret": "xxx",
        "user_id": "xxx",
        "enable_img": True  # 是否发送图表截图
    }
}
```

飞书机器人创建步骤参见 `cookbook/docs/服务依赖.md`。

## Web 服务

### 启动

```bash
cd web/chanlun_chart
python app.py
# 默认端口 9900，浏览器自动打开 http://127.0.0.1:9900
```

带参数启动：
```bash
python app.py nobrowser    # 不自动打开浏览器
```

### Web 功能一览

| 功能 | 路径 | 说明 |
|------|------|------|
| 行情图表 | `/` | TradingView 图表 + 缠论标注 |
| 缠论配置 | `/get_cl_config/` | 调整分型/笔/线段/中枢等参数 |
| 自选股 | `/zixuan_group/` | 管理自选分组 |
| 行情监控 | `/alert_list/` | 设置监控任务，自动发送飞书告警 |
| 选股筛选 | `/xuangu/task_list/` | 按缠论条件筛选标的 |
| AI 分析 | `/ai/analyse` | 调用 AI 分析市场走势 |
| 后台任务 | `/jobs` | 查看 APScheduler 任务状态 |
| 系统设置 | `/setting` | 代理、飞书等运行时配置 |

### PM2 部署（生产环境）

```bash
# 安装 PM2
npm install -g pm2

# 启动 Web 服务
pm2 start script/chanlun_web.config.js

# 查看状态
pm2 status

# 查看日志
pm2 logs chanlun_web

# 重启
pm2 restart chanlun_web
```

PM2 配置文件示例（`script/chanlun_web.config.js`）：

```javascript
module.exports = {
    apps: [{
        name: "chanlun_web",
        script: "web/chanlun_chart/app.py",
        interpreter: "/path/to/conda/envs/chanlun/bin/python",
        args: "nobrowser"
    }]
};
```

## 数据同步

### 手动同步

```bash
# 同步所有加密货币合约数据
python script/crontab/reboot_sync_currency_klines.py

# 同步 Binance 现货数据
python script/crontab/reboot_sync_currency_spot_klines.py
```

### 定时同步

推荐使用系统 crontab 或 PM2 定时任务：

```bash
# crontab 示例：每 5 分钟同步一次
*/5 * * * * cd /path/to/chanlun-pro && /path/to/python script/crontab/reboot_sync_currency_klines.py >> /tmp/sync.log 2>&1
```

### 同步脚本配置

以 `reboot_sync_currency_klines.py` 为例，可调整：

```python
# 同步的周期列表
frequencys = ["w", "d", "4h", "60m", "30m", "15m", "10m", "5m", "1m"]

# 各周期的起始同步时间
f_start_datetime = {
    "w": "2000-01-01",
    "d": "2000-01-01",
    "4h": "2000-01-01",
    # ...
}

# 只同步指定代码（默认同步所有）
run_codes = None  # 或 ["BTC/USDT", "ETH/USDT"]
```

## 行情监控与告警

### Web 端配置

1. 进入 `/alert_list/{market}` 页面
2. 创建监控任务，设置：
   - 标的列表（或自选分组）
   - 监控频率（分钟/小时级别）
   - 监控条件（笔背驰、买卖点、MA 交叉、MACD 交叉等）
3. 命中条件时自动发送飞书消息

### 监控条件类型

| 条件 | 说明 |
|------|------|
| 笔类型 | 向上笔/向下笔 |
| 笔背驰 | MACD 力度比较 |
| 笔买卖点 | 1买/2买/3买/类二买/类三买 |
| 线段类型/背驰/买卖点 | 同笔，但在线段级别 |
| MA 交叉 | 双均线金叉/死叉 |
| MACD 交叉 | 金叉/死叉 |

### 截图推送

如果配置了 `enable_img: True`，监控触发时会：
1. 用 `pyecharts` 渲染缠论图表
2. 用 `Playwright` (Chromium) 将 HTML 转为 PNG
3. 上传 PNG 到飞书消息

需要预先安装 Playwright 浏览器：

```bash
playwright install chromium
```

## 选股筛选

### Web 端

`/xuangu/task_list/{market}` 页面支持的筛选策略：

| 策略 | 说明 |
|------|------|
| `xg_single_bi_1mmd` | 单周期笔一类买卖点 |
| `xg_single_bi_2mmd` | 单周期笔二类买卖点 |
| `xg_single_bi_3mmd` | 单周期笔三类买卖点 |
| `xg_single_find_3buy_by_1buy` | 中枢内 1 买后出现 3 买 |
| `xg_single_find_3buy_by_zhuanzhe` | 趋势转折后的 3 买 |
| `xg_single_xd_and_bi_mmd` | 线段+笔同时有买点 |
| `xg_multiple_xd_bi_mmd` | 多周期线段+笔筛选 |
| `xg_multiple_low_level_12mmd` | 多周期低级别 1/2 买点|
| `xg_single_ma_250` | MA250 过滤 |

### 脚本端

```python
python script/crontab/run_history_xuangu.py
```

支持多进程（默认 24 workers）并行筛选，结果保存到 pkl 文件和自选分组。
