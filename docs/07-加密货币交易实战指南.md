# 加密货币交易实战指南

> 本文档专门面向希望使用 chanlun-pro 进行加密货币（BTC/USDT、ETH/USDT 等）交易的开发者，覆盖从数据同步到实盘交易的完整流程。

## 整体流程

```
1. 环境配置（Binance API、代理）
      ↓
2. 数据同步（历史 K 线 → 本地 DB）
      ↓
3. 策略编写与回测
      ↓
4. 参数优化
      ↓
5. 模拟验证（signal → trade 转换）
      ↓
6. 实盘部署
```

## 第 3 步：策略编写

### 从 StrategyDemo 开始

项目自带的 `StrategyDemo` 是最好的起点。它的逻辑是：

1. 获取最后一根已完成的笔
2. 检查笔上是否有买卖点（MMD）
3. 检查笔是否出现停顿（确认信号的关键）
4. 开仓，止损设在笔的极值
5. 平仓条件：反方向笔出现反向信号或背驰

### 编写你自己的策略

建议以 `my_` 前缀命名（会被 .gitignore 忽略）：

```python
# src/chanlun/strategy/my_crypto_strategy.py

from chanlun.backtesting.base import *
from chanlun.cl_interface import *

class MyCryptoStrategy(Strategy):
    """
    基于笔级别1买/2买 + ATR止损的加密货币策略
    """
    _max_loss_rate = 5  # 最大亏损 5%
    
    def open(self, code, market_data, poss):
        opts = []
        cd = market_data.get_cl_data(code, market_data.frequencys[0])
        
        bis = cd.get_bis()
        bi_zss = cd.get_bi_zss("zs_type_bz")
        
        if len(bis) < 3 or len(bi_zss) < 1:
            return opts
        
        last_bi = self.last_done_bi(cd)
        if last_bi is None:
            return opts
        
        # 只关注做多（现货交易场景）
        if last_bi.type != "down":
            return opts
        
        # 只要 1买 和 2买
        target_mmds = ["1buy", "2buy"]
        for mmd in last_bi.line_mmds():
            if mmd.name not in target_mmds:
                continue
            if mmd.name in poss:
                continue
            
            # 笔停顿确认
            if not self.bi_td(last_bi, cd):
                continue
            
            # ATR 止损
            loss_price = self.get_atr_stop_loss_price(
                None, cd, period=14, m=2.0
            )
            
            opts.append(Operation(
                code=code, opt="buy", mmd=mmd.name,
                loss_price=loss_price,
                msg=f"{mmd.name} ATR止损={loss_price}"
            ))
        
        return opts
    
    def close(self, code, mmd, pos, market_data):
        cd = market_data.get_cl_data(code, market_data.frequencys[0])
        price = market_data.last_k_info(code)
        
        # 1. 止损检查
        loss_opt = self.check_loss(mmd, pos, price)
        if loss_opt:
            return loss_opt
        
        # 2. 回撤止损：盈利 3% 后，回撤 50% 即平仓
        if pos.max_profit_rate > 3:
            back_opt = self.check_back_return(mmd, pos, price, back_rate=50)
            if back_opt:
                return back_opt
        
        # 3. 寻找卖点
        bis = cd.get_bis()
        last_bi = self.last_done_bi(cd)
        if last_bi and last_bi.type == "up":
            if last_bi.mmd_exists(["1sell", "2sell"], None):
                return Operation(
                    code=code, opt="sell", mmd=mmd,
                    msg="上涨笔出现卖点"
                )
        
        return None
```

## 第 5 步：实盘部署

### 实盘交易器（TraderCurrency）

`src/chanlun/trader/trader_currency.py` 是 Binance 合约的实盘交易器，继承自 `BackTestTrader`：

```python
class TraderCurrency(BackTestTrader):
    def __init__(self):
        super().__init__("currency", mode="online", ...)
        self.ex = ExchangeBinance()
        self.poss_max = 8       # 最大持仓数
        self.leverage = 2       # 杠杆倍数
    
    def open_buy(self, code, opt):
        """开多：计算仓位 → Binance API 下单 → 飞书通知 → 记录DB"""
    
    def open_sell(self, code, opt):
        """开空：同上"""
    
    def close_buy(self, code, pos, opt):
        """平多：查询实际持仓 → 平仓 → 飞书通知 → 记录DB"""
    
    def close_sell(self, code, pos, opt):
        """平空：同上"""
```

### 启动实盘

参考 `script/trader/reboot_trader_currency.py`：

```python
# my_live_trader.py

import time
from chanlun.exchange.exchange_binance import ExchangeBinance
from chanlun.trader.trader_currency import TraderCurrency
from chanlun.trader.online_market_datas import OnlineMarketDatas
from chanlun.strategy.my_crypto_strategy import MyCryptoStrategy

# 初始化
ex = ExchangeBinance()
trader = TraderCurrency()
trader.set_strategy(MyCryptoStrategy())

frequencys = ["30m"]
cl_config = {"bi_type": "bi_type_old", "zs_bi_type": ["zs_type_bz"]}

market_data = OnlineMarketDatas("currency", frequencys, ex, cl_config)

# 要交易的标的
codes = ["BTC/USDT", "ETH/USDT"]

# 从 Redis 恢复上次状态
trader.load_from_pkl("trader_my_crypto")

# 主循环
while True:
    try:
        market_data.clear_cache()  # 清缓存获取最新数据
        
        # 加入当前持仓代码（避免遗漏平仓检查）
        run_codes = list(set(
            codes + [p.code for p in trader.hold_positions().values()]
        ))
        
        for code in run_codes:
            trader.run(code)
        
        # 持久化状态
        trader.save_to_pkl("trader_my_crypto")
        
    except Exception as e:
        print(f"异常: {e}")
    
    time.sleep(5 * 60)  # 每 5 分钟执行一次
```

### 仓位管理

`TraderCurrency` 的默认仓位逻辑：

```
单仓金额 = 可用余额 / 剩余仓位数 × 0.98 × 杠杆倍数
```

例如：余额 10000 USDT，最大持仓 4，杠杆 2x，已有 1 仓：
- 单仓 = 10000 / 3 × 0.98 × 2 ≈ 6533 USDT

### 飞书通知

实盘交易器会自动发送飞书消息：
- 开仓通知：代码、方向、信号名、数量
- 平仓通知：代码、方向、盈亏率、说明
- 异常通知：下单失败等错误信息

确保 `config.py` 中正确配置了 `FEISHU_KEYS["currency"]`。

## 关键注意事项

### 现货 vs 合约

| 特性 | 合约 (`CURRENCY`) | 现货 (`CURRENCY_SPOT`) |
|------|-------------------|----------------------|
| Exchange 类 | `ExchangeBinance` | `ExchangeBinanceSpot` |
| 做空 | ✅ 支持 | ❌ 不支持 |
| 杠杆 | ✅ 支持 | ❌ 不支持 |
| 交易实现 | ✅ 完整 | ❌ 需自行实现 |
| 数据获取 | ✅ 完整 | ✅ 完整 |

> 如果你想做现货交易，需要在 `ExchangeBinanceSpot` 中实现 `balance()`、`positions()`、`order()` 方法，并编写对应的 `TraderCurrencySpot`。

### 手续费

Binance 合约手续费参考：
- Maker: 0.02%
- Taker: 0.04%（市价单属于 Taker）
- 回测中建议设 `fee_rate = 0.0006`（含滑点估算）

### 风险管理

1. **止损是必须的** — Strategy 的 `check_loss()` 方法
2. **仓位控制** — `max_pos` 限制最大持仓数
3. **杠杆谨慎** — 加密货币波动大，建议 2x 以下
4. **小资金验证** — 先用小资金跑一段时间确认策略稳定

### 回测到实盘的 checklist

- [ ] 回测收益曲线平稳、无过拟合嫌疑
- [ ] 手续费设置合理（含滑点）
- [ ] 最大回撤可接受
- [ ] 多个时间段回测验证（牛市、熊市、震荡市）
- [ ] config.py API Key 配置正确
- [ ] 代理连接稳定
- [ ] Redis 可用（实盘状态持久化）
- [ ] 飞书通知配置正确
- [ ] 先用小资金运行至少 1 周
